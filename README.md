# user_growth_analysis
# 用户增长与留存及渠道投入效率分析

## 项目简介

本项目基于公开的 Y.Afisha 用户行为与营销数据集，使用 MySQL、Python 和 Excel，分析用户从首次访问到购买及后续回访的过程，评估用户增长、活跃留存、购买转化与渠道营销投入效率，并提出可验证的业务优化建议。

分析时间范围：2017-06-01 至 2018-05-31。

## 分析内容

- **用户增长与活跃分析：** 分析首次访问用户规模、增长趋势、DAU、WAU、MAU 及用户黏性。
- **用户留存与生命周期分析：** 计算 D1、D7、D30 留存率，开展 Cohort 同期群分析，并划分新访客、持续活跃、沉默及回流用户。
- **购买转化分析：** 分析首次访问后的购买转化，并比较不同观察窗口下的转化表现。
- **渠道投入效率分析：** 对比不同首次访问渠道的用户规模、购买转化率、获客成本（CAC）、收入 LTV 及广告支出回报率（ROAS）。
- **业务建议：** 识别值得优先审查的渠道与用户运营问题，提出预算优化、首购转化及沉默用户召回的验证方案。

## 技术栈

- **MySQL：** 多表关联、数据清洗、窗口函数、用户首访识别、指标提取与独立核验。
- **Python：** Pandas 数据处理、指标计算、数据质量检查、可视化及结果验证。
- **Excel：** 交互式 Dashboard、指标卡、原生图表及月份和渠道筛选。

## 核心发现

- 观察期内共有 **228,169 名访客**，其中 **36,522 名用户发生购买**，观察期购买转化率为 **16.01%**。
- 严格次日、7 日和 30 日回访留存率分别为 **2.58%、0.65% 和 0.25%**。
- 新增访客于 2017 年 11 月达到峰值，随后总体回落。
- 不同渠道的用户规模、购买转化率和获客成本存在差异；渠道 3 的观测 ROAS 为 **0.386**，固定 30 日 ROAS 为 **0.294**，值得优先开展渠道结构与投放活动审查。
- 整体观测 ROAS 为 **0.766**，已记录收入低于已记录营销费用，后续应结合完整成本和实验数据进一步评估实际商业价值。

## 分析说明与局限

本项目为基于历史数据的描述性分析与渠道归因比较，并未实施真实营销实验。首次观测访问用户不等同于真实注册新用户；ROAS 衡量收入与营销费用的比值，不代表利润或因果增量。数据还存在异常低流量日期、部分渠道费用缺失及长期用户价值观察不足等限制，相关结论均在报告中说明。
